# ApexAI — studio de contenu (branche `content-studio`)

Branche orpheline du dépôt front : elle ne touche jamais l'app (aucun lien avec `main`).
Elle contient la machine à contenu d'ApexAI utilisée par la tâche planifiée « ApexAI — studio de contenu ».

- `apex-promo-video/apexai-video/` : projet Remotion (films, kit social, gabarits `T-*`). `npm install` puis `npx remotion still|render <id>`.
- `apex-promo-video/assets/` : charte (`brand/tokens.json`), données réelles de démo, captures.
- `apex-social/` : logos, bibliothèque de sons (`out/07-son`), playbook CM, calendriers.
- `studio/` : stratégie, gabarits de production quotidienne, journal.
